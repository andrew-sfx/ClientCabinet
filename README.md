# ClientCabinet — передача разработчикам, 02.11.2026

Обновлённый снимок текущего продуктового кода. SOURCE-BASE.txt указывает исходный HEAD; SOURCE-MANIFEST.json фиксирует хеши src и tests. История внутреннего проекта, дизайн-исследования, локальные данные и настройки агентов исключены.

## Запуск

Node 24.22.1 / npm 11.19.1:

```powershell
npm ci
npx playwright install chromium
npm run check
npm run dev
```

Адрес http://localhost:5173; preview — http://localhost:4173. По умолчанию API https://api3.soft-fx.com, домен client.soft-fx.com; VITE_API_URL/VITE_DOMAIN_NAME задаются до запуска или сборки и публичны. Для сборки и синтетических тестов учётные данные не нужны.

## Состав

Вход/Identity, регистрация, сессия/refresh/выход, главная, торговые счета, выбор способа и формы пополнения. Наличие кода не доказывает живую интеграцию каждого сценария. Другие разделы реестра без component не реализованы. Файлы tests содержат синтетические данные и ручные интеграционные страницы.

Реальные формы пополнения могут создавать платёжные запросы; регистрация создаёт данные, выбор валют сохраняет настройки. Такие проверки допустимы только на согласованном стенде с разрешённым тестовым аккаунтом. Не выполнять реальные денежные операции ради проверки передачи.

## Проверки

npm run check: lint, unit/contract, токены, TypeScript, build, документы пакета, Chromium UI. npm run check:api отдельно проверяет публичный Swagger относительно переданного baseline, который автоматически не обновляется. Тематический baseline не покрывает все новые методы. Итог подготовки — VALIDATION.md.

Токены хранятся в localStorage и доступны JavaScript. Реальные учётные данные и HAR не сохранять в проекте. Лицензии шрифтов включены. Условия использования и права определяются договорённостями сторон.
