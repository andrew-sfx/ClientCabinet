# Передача разработчикам

Снимок обновлён 02.11.2026 по поручению владельца после сообщения о пройденном ревью. Это решение владельца, а не новое независимое ревью каждого последующего изменения.

Карта: src/auth — API/сессии/регистрация; src/cabinet/api.ts — данные главной и настройки; src/cabinet/trading — торговые счета; src/cabinet/deposit — способы и формы пополнения; router/sections/CabinetShell — маршруты и оболочка. tests/*.test.mjs и scripts/test-ui.mjs — повторяемые синтетические проверки. Сетевые обращения UI-тестов вне локального сервера блокируются.

Проверить ошибки/таймауты, отмену и поздние ответы, обновление сессии, работу нескольких вкладок, маршруты, валидацию данных, идемпотентность/неоднозначные результаты создающих запросов. Браузерные синтетические проверки не подтверждают идемпотентность backend или исполнение финансовых операций.

В пакет включены минимальные дизайн-токены и API baseline; внутренние архивы и полный Swagger исключены. История основного проекта не переносится. Права доступа к GitHub выдаются персонально только к данному репозиторию.
